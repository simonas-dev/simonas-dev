# M4 — Content pages

Question: best implementation plan for M4 of PLAN.md given scout context (`.council/M4-scout.md`).
Scope: M4 checklist + `static/paper.png` / `paper-dark.png`. Non-goals: M5 htmx (keep `div.page`/`main#main` untouched as swap target), M6 polish.

## Plan (ordered steps)

1. **Textures**: generate `static/paper.png` (dark specks, day) and `static/paper-dark.png` (light specks, night) as small tileable **alpha grain** PNGs (128–256 px, ≤ 20 KB each; per-pixel noise so tiling is seamless; ffmpeg or pure-Python zlib — no new repo tooling). Opaque textures are rejected (they would hide backdrop blur and the colour layer).
2. **Tokens (styles.css)**: `:root { --paper-texture: url(/paper.png); --tint: 97%; --surface-pad: clamp(1.25rem, 4vw, 3.5rem); }`, `.theme-night { --paper-texture: url(/paper-dark.png); }`. Reuse the texture on the mobile menu panel (existing hook) and `.no-webgl body` (closes the M1/M2 deferral). Tune texture alpha so grain is visible but quiet under the tint (screenshot check, day + night).
3. **`.content-surface`**: `box-sizing: content-box; max-width: var(--measure); margin-inline: auto; padding: var(--surface-pad); background-color: color-mix(in srgb, var(--surface) var(--tint), transparent); background-image: var(--paper-texture); -webkit-backdrop-filter / backdrop-filter: blur(8px)`. No radius/shadow/border. `.content-surface.wide` for photos (wider max-width, still inside `--frame-inline`).
4. **Prose (scoped to `.content-surface`)**: Newsreader body at `--lh` 1.6; headings 400; spacing for h2/p/lists; italic blockquote with 1px rule; `hr` subtle; block images max-width 100%; links underlined (existing). Mono (`--font-mono`, `--mono-size`) for `code`, `pre`, `time`, `.meta`; `pre { overflow-x: auto }`. No syntax highlighting. Mono metadata opacity ≥ 0.75. No horizontal overflow at 390 px.
5. **Templates** (leave `div.page`/`main` in base.html untouched):
   - `page.html`: `<article class="content-surface{% if page.extra.wide %} wide{% endif %}">` (no template h1; markdown has one).
   - `post.html`: same wrapper; h1 + `<p class="meta"><time datetime="YYYY-MM-DD">…</time> · {{ page.reading_time }} min read</p>` (show at least 1 min).
   - `section.html`: wrapper; unbulleted list, serif title link + mono date · reading time.
   - `index.html`: no surface (home keeps full-speed ocean).
   - Header readability: if scrolled panel text collides with header chrome on content pages, add a light top paper scrim for header chrome (mirroring the footer scrim) — check by screenshot.
6. **Photos**: `content/photos.md` `[extra] wide = true`. Shortcode `templates/shortcodes/photo.html` emitting `<figure class="bleed"><picture><source type="image/webp" srcset="… 1200w, … 2400w" sizes="…"><img src="original.JPG" width height alt loading="lazy" decoding="async"></picture></figure>`, with an `eager` param for the first photo (LCP). Prefer Zola `resize_image(..., format="webp")` (generated at build, nothing committed); if it can't read `static/` paths, commit `cwebp` outputs next to the JPGs. Bleed to the **panel edges** (negative inline margin = `--surface-pad`), never 100vw. `config.toml [markdown]`: enable lazy/async images for markdown images if the 0.23 option exists (verify name).
7. **Content-mode throttle**:
   - `ocean.js` gets generic knobs only: `res: 1, fps: 0, resize: onResize` on the state; in `applySize` `scale = tier.scale * (probe ? 1 : state.res)`; at top of `frame()` `if (!probe && state.fps && now - lastFrameTime < 1000 / state.fps - 8) { rafId = requestAnimationFrame(frame); return; }` (tolerance so 60 Hz vsync gives ~15 fps, not 12); `sizeDirty = true` when the probe settles. **Probe always runs at full res, uncapped** so tier caching is not corrupted. Pay by trimming comments; must stay ≤ 10,240 B. If it can't fit: stop and report (do not raise the budget).
   - `site.js` `oceanMode()` (named, re-callable for M5 afterSwap): `.content-surface` present → `speed .15, res .5, fps 15`, else `1, 1, 0`; call `resize()`; guard missing `__ocean`. Call at init.
8. Validate (see Acceptance). Harness in `/tmp/pw` (`m4check.mjs` from m3check pattern; use polling waits, not fixed sleeps).

## Acceptance checks

- **Surface**: present on `/about/`, `/posts/`, `/posts/ballistic-wizard/`, `/photos/`; absent on `/`. Computed bg alpha 0.97, `backdrop-filter` has blur, text column ≤ 68ch (photos `.wide`). Grain visible in day and night screenshots (panel pixel std-dev > 0). NOGL body textured; menu panel textured. PNGs ≤ 20 KB each. Ink contrast on surface ≥ 7:1 day and night.
- **Prose**: Newsreader, line-height = 1.6 × font-size; `time`/`.meta`/`code` in Departure Mono; no horizontal overflow at 390 px.
- **Posts**: `/posts/` lists title, date, reading time; post shows `<time datetime="2024-06-27">` and "N min read" (N ≥ 1); `/feed.xml` 200 with `<item>`/`pubDate`; `/posts/wizard` alias still works.
- **Photos**: `<picture>` with WebP `<source>` + JPEG `<img>` fallback; width/height set; first photo eager, rest lazy; WebP URLs return 200; no horizontal overflow; images reach panel edges at 390 and 1440.
- **Throttle**: on `/about/` after probe: `__ocean.speed === .15`, canvas.width ≈ 0.5 × home width at same tier, draw rate ≈ 15 ± 3 fps; on `/` full rate and res. Fresh session landing on `/posts/` caches the same tier as `/`. Static tier still OK. `ocean.js` ≤ 10,240 B; `node --check`; `zola check` + `zola build`; no console errors; lifecycle.mjs + m3check.mjs still pass.

## Outcome

**Shipped:**
- **Paper textures:** `paper.png` and `paper-dark.png`, 256² tileable alpha grain, about 19.7 KB each. They're used on surfaces, on the mobile menu, and on the no-WebGL body.
- **`.content-surface`:** 97% `color-mix` tint over the grain, with `blur(8px)`. Widths are 68ch, or 64rem for the `.wide` photos page.
- **Prose:** Newsreader at 1.6 line height; Departure Mono for metadata and code.
- **Posts:** the list and the post template show the date and "N min read" (minimum 1).
- **Photos:** a Zola 0.23 *component* `photo` (Zola 0.23 replaced shortcodes with components) produces a WebP srcset at 1200w and 2400w via `resize_image` at build time, with a JPEG fallback and width/height set. The first photo loads eagerly with high fetch priority; the rest are lazy.
- **Header scrim:** added on content pages.
- **Content-mode throttle:** the policy lives in `site.js` `oceanMode()`, which M5 can re-call. `ocean.js` gets generic `res`/`fps`/`resize` knobs, and the quality probe is exempt from them. Measured on content pages: 15.0 fps, 0.5× resolution (canvas 256 vs 512), and speed 0.15. Landing on `/posts/` first caches the same tier as landing on `/`.

**Validation:**
- `zola check` and `zola build` pass.
- `ocean.js` is 10,238 B of the 10,240 B budget, leaving **2 B of headroom**.
- The m4check, m3check and lifecycle harnesses pass.
- Worst-case ink contrast on surfaces is 9.97 in day and 8.83 at night.
- WebP sizes:

  | Image | 1200w | 2400w |
  |---|---|---|
  | DSCF2021 | 37 KB | 110 KB |
  | R1 | 174 KB | 550 KB |

**Deferred:**

- Texture on the scrims for the no-WebGL fallback (cosmetic).
- The night scrim is darker than the surface at the top edge (cosmetic).
- `settleStatic` doesn't mark the size dirty, so a single frame differs (cosmetic).
- Everything listed in the earlier Deferred section.
