## Plan (ordered steps)

1. **decisions.md** (append rows only): ocean.js budget → 11,264 B raw, no minify step; shader logo deferred (superseded by HTML mono wordmark).
2. **site.js** (rewrite-sea doesn't touch it):
   - Reduced motion: `matchMedia('(prefers-reduced-motion: reduce)')` multiplies the mode speed by 0.3 inside `oceanMode()` (home 0.3, content 0.045), with a `change` listener. Grain untouched (u_grainTime ignores speed).
   - Speed tween: generalise the smoothstep tween so `oceanMode()` tweens `speed` over ~600 ms (instant under reduced motion); `res`/`fps` stay instant.
   - `aria-current="page"` on nav links (both copies): server-side in base.html via `current_path`, and updated in `afterPageChange` after swaps. Persistent underline style like hover.
3. **ocean.js** (edits only in buildProgram, draw, and a new listener near the bottom; never lines ~11–32):
   - Visibility pause: on hidden → `stopLoop()`; on visible, if started && program && !isStatic && !rafId && context not lost → `lastFrameTime = 0`, reset an in-progress probe's samples (keep stepsDown), request a frame. The hidden gap must never push the probe down a tier.
   - Ripples plumbing: look up `u_ripples` in buildProgram on its own line (not via UNIFORM_NAMES); in draw, `uniform4fv` from `state.ripples` (Float32Array(40)) when the location exists; expose `state.wave = waveTime`.
   - Must stay ≤ 11,264 B.
4. **GLSL** (new uniforms after the existing uniform block; new functions placed just above/after `sky()`; header `#define`s/consts and wave functions untouched):
   - `stars(dir)`: hashed grid on dir, sparse, no twinkle, cell ≥ 2 backing px at the lowest scale, faded out near the horizon, × u_night, max ~+0.15. Added only in the direct-sky branch of main (`sky(ray) + stars(ray)`) so reflections stay calm.
   - Moon/sun glow: inside `sky()`, crossfade the sun lobe to a tighter, dimmer moon lobe + soft halo with u_night (don't change SUN_DIR). Day output (u_night=0) identical.
   - Ripples: `uniform vec4 u_ripples[10]` (screen uv xy, wave time at click, unused/strength). `rippleNormal(p)` intersects each ripple's screen ray with y=0 using existing `cameraRay`/`intersectPlane` (no duplicated camera consts — follows M6a's values automatically after merge), 1–2 soft rings, ~3–4 s life in wave time, amplitude well below a crest. Applied with one new line `N = normalize(N + rippleNormal(hit.xz));` placed after the existing normal computation, away from the eps line (keep ≥1 untouched line between).
5. **Ripple input (site.js)**: primary-button `pointerdown`, ignored on `a, button, summary, details, input, header, footer, .content-surface`, on content pages, under reduced motion, when `__ocean` missing or tier static; uv = ((2cx − W)/H, (H − 2cy)/H) in canvas CSS px; ring buffer of 10 in `__ocean.ripples`; clicks above the horizon simply don't intersect (shader skips rays with dir.y ≥ −0.01).
6. **Head + assets**:
   - `static/favicon.svg`: pixel "S" in the Departure Mono grid as rects/paths (no webfont), `@media (prefers-color-scheme: dark)` flips #353431/#faf9f6 → #e8e6e1/#1a1a1a. Keep `favicon.ico`; add `apple-touch-icon.png` 180 px on opaque paper.
   - `static/og.png` (or .jpg) 1200×630, ≤ 120 KB: settled day ocean frame + mono wordmark only (no hero text), rasterised with Playwright from a /tmp page.
   - base.html head (one new hunk): og:title/description/url/image (absolute via `get_url`/`config.base_url` — don't edit config.toml), og:type, twitter:card summary_large_image, icon links (`favicon.svg`, `favicon.ico sizes=32x32`, apple-touch-icon).
   - `templates/404.html` extends base: `.content-surface` with mono "404", one serif sentence, link home. No About link.
7. **Measure**: Lighthouse via `npx -y lighthouse` (into /tmp, CHROME_PATH = Playwright chromium) on `/`, `/posts/`, `/404.html`; record scores (perf advisory under SwiftShader). If no network, record skipped and use Playwright for JS bytes/console.

## Outcome

- **Click ripples:** `u_ripples[10]` on a site.js ring buffer. The click is projected in GLSL through `cameraRay`/`intersectPlane`, so the M6a camera is followed automatically.
