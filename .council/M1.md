# M1 — Ocean shader

Question: best implementation plan for M1 of PLAN.md given scout context (`.council/M1-scout.md`).
Scope: M1 checklist + PLAN "Shader notes". Non-goals: fonts/horizon export (M2), theme/u_night animation (M3), content throttle + paper.png (M4), htmx (M5), ripples/logo/stars/reduced-motion/visibilitychange (M6).

## Plan (ordered steps)

1. **`static/styles.css`**: `#ocean { opacity:0; image-rendering:auto; transition: opacity 1000ms cubic-bezier(0.333333,0,0.666667,1); }` and `.shader-ready #ocean { opacity:1 }` (class on `<html>`). Body stays `#faf9f6` — this is the no-JS / no-WebGL fallback.
2. **`templates/base.html`**: in `<head>`: `<link rel="preload" href="/shader/ocean.vert.glsl" as="fetch" crossorigin>`, same for frag, and `<script src="/ocean.js" defer></script>`. Exactly one `<script` per page.
3. **`static/shader/ocean.vert.glsl`**: GLSL ES 1.00 full-screen triangle/quad.
4. **`static/shader/ocean.frag.glsl`** (GLSL ES 1.00, `precision highp float`):
   - Uniforms: `iResolution, iTime, u_waveTime, u_grainTime, u_night, u_noiseScale` — all six actually used.
   - `wavedx`/`getwaves` verbatim from PLAN (constants 0.82, 1.18, 1.07, 1232.399963, 0.38, `exp(sin(x) - 1.0)`), loop bound raised to a constant 36 with `if (i >= iters) break;` so normals can use more octaves.
   - Iteration counts from `#define ITERS_RAYMARCH` / `ITERS_NORMAL`, prepended by JS per tier.
   - afl_ext raymarch between two water planes (DEPTH ~1.0), `intersectPlane`, finite-difference normal with distance smoothing, Fresnel `0.04 + 0.96*pow(1-…,5)`, reflection of a **simple sky** (vertical gradient + static soft sun lobe; no animated sun, no ACES), scattering term.
   - Fixed camera: no mouse; slight downward pitch, FOV and height as named `const`s (documented so M2 can derive `--scene-horizon-from-bottom`); origin drifts slowly with `u_waveTime`.
   - Post pass from PLAN verbatim in a `vec3 post(vec3 color, vec2 uv)` function, plus a defined `gaussian(z, mu, sigma)` (normal PDF). **Deviation (decided):** day endpoints tinted to paper: `light` day = `vec3(0.980, 0.976, 0.965)` (#faf9f6), `dark` day = warm-tinted ~0.62 equivalent (e.g. `vec3(0.62, 0.615, 0.60)`); night endpoints as PLAN. `uv` for grain in backing pixels.
5. **`static/ocean.js`** (plain IIFE, `defer`, no module, no deps; re-init guard `window.__ocean`):
   - `getContext('webgl', {antialias:false, alpha:false, depth:false, powerPreference:'low-power'})`; require highp fragment precision; otherwise fallback.
   - Fetch both GLSL files with `Promise.all`; compile/link with info log to console on failure → fallback.
   - Fallback = stop loop, ensure no `shader-ready`, add `html.no-webgl`; canvas stays invisible, flat paper shows.
   - Backing size = `round(clientWidth*scale) × round(clientHeight*scale)` (DPR ignored for size, used only for starting tier), width capped ~1024; `ResizeObserver` (or debounced resize). `iResolution` = backing size.
   - Uniforms per frame: `iTime` = seconds since start; `u_waveTime += min(dt, 0.1) * speed` (state object exposes `speed` for M4); `u_grainTime` stepped at 24 Hz; `u_night = state.night` (0 for now); `u_noiseScale` constant tuned so grain ≈ one backing pixel.
   - **Quality tiers**: high `{scale:0.4, raymarch:12, normal:24}`, med `{0.375, 10, 16}`, low `{0.35, 8, 10}`. Start: DPR ≥ 2 with small viewport (≤ 900 CSS px wide) or `hardwareConcurrency ≤ 4` → med, else high; reuse a tier cached in `sessionStorage`.
   - **Probe while invisible** (opacity 0): skip 10 warm-up frames, median rAF delta over 30 frames; > 20 ms → step down a tier (recompile with new defines), max twice. If still > 33 ms at low: draw a single static frame and stop the loop. Then add `shader-ready` to `<html>` after the next drawn frame. Cache the final tier in `sessionStorage`.
   - `webglcontextlost`: `preventDefault`, stop loop, remove `shader-ready`; `webglcontextrestored`: re-run init.
6. Validate (see Acceptance). Headless browser: if no Chrome, try installing Playwright Chromium in a **temp dir outside the repo** (e.g. `/tmp/pw`) and screenshot `zola serve` with SwiftShader; don't add Node tooling to the repo.

## Acceptance checks

- Quad + low-res: built HTML has `<script src="/ocean.js" defer>`, CSS has `image-rendering:auto`; JS backing = client × scale with scale ∈ {0.35, 0.375, 0.4}, no DPR multiplier.
- Raymarcher: frag contains PLAN getwaves constants verbatim, a finite-difference normal (cross product), a sky function, raymarch loop.
- Post pass: frag contains `0.299, 0.587, 0.114`, a `gaussian(` definition, `mix(dark, light, gray)`, grain formula with `43758.5453` and `u_grainTime * 1.5`.
- Uniforms: all six names declared in frag and looked up in `ocean.js`; JS tolerates null locations.
- Quality + fallback: tier table, median probe, sessionStorage cache, static-frame bail-out, null-context/compile-fail fallback present. Headless (if available): with WebGL → `shader-ready` set, screenshot shows greyscale ocean with grain and horizon; with WebGL disabled → no class, flat `#faf9f6`, no uncaught errors.
- Fade: CSS rule with 1000ms transition; class added only after probe + first visible frame.
- Global: `zola check` + `zola build` exit 0; `curl` 200 for `/ocean.js`, `/shader/ocean.vert.glsl`, `/shader/ocean.frag.glsl`; `node --check static/ocean.js`; `ocean.js` < 10 KB, GLSL total < 8 KB unminified; only one `<script` per page.
