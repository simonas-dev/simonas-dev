# M2 — Typography & chrome

Question: best implementation plan for M2 of PLAN.md given scout context (`.council/M2-scout.md`).
Scope: M2 checklist only. Non-goals: theme toggle logic / prefers-color-scheme / u_night animation (M3), paper.png + content surfaces + prose (M4), htmx + menu close on swap (M5), favicons/SVG logo/subsetting/size-adjust (M6).

## Plan (ordered steps)

1. **Fonts** — `static/fonts/`: `DepartureMono-Regular.woff2` (v1.500, from the GitHub release zip), `newsreader-latin-400-normal.woff2`, `newsreader-latin-400-italic.woff2` (@fontsource/newsreader 5.3.0, static, latin), plus `OFL-DepartureMono.txt` and `OFL-Newsreader.txt`. Download to /tmp, copy only these files into the repo. No variable/bold files; headings at 400 with `font-synthesis: none`.
   - `static/styles.css`: three `@font-face` with `font-display: swap`; stacks `--font-serif: "Newsreader", Georgia, serif`, `--font-mono: "Departure Mono", ui-monospace, Menlo, monospace`.
   - `templates/base.html`: `<link rel="preload" as="font" type="font/woff2" crossorigin>` for Departure Mono and Newsreader regular only (italic on demand). Add `<meta name="color-scheme" content="light">` (M3 switches it).
2. **Tokens** in `:root` (styles.css):
   - `--paper: #faf9f6; --ink: #353431;` body uses them. `.theme-night { --paper: #1a1a1a; --surface: #2e2d2b; --ink: #e8e6e1; color-scheme: dark; }` — defined only, not activated; **no** `prefers-color-scheme` rule in M2.
   - `--frame-inline` / `--frame-block`: `clamp(20px, 5.2vw, 75px)`.
   - Serif scale in rem with `clamp()` (max ≤ 2.5× min): e.g. `--step-0: clamp(1.0625rem, .98rem + .35vw, 1.25rem)`, `--step-1`, `--step-2`, `--step-3: clamp(2rem, 1.2rem + 3.2vw, 3.75rem)`.
   - Mono UI size fixed (not clamped), pixel-friendly (e.g. 11px multiples: 11px/22px → use `--mono-size` ≈ 0.6875rem–0.875rem; pick the crispest that is ≥ ~11px and check screenshot).
   - `--lh: 1.6`, `--measure: 68ch` (defined, used M4), `--ease: cubic-bezier(0.333333,0,0.666667,1)`, `--dur-theme: 900ms`; canvas transition uses `var(--ease)`.
   - Links: `color: inherit`, thin underline with offset (fixes M1 blue-link contrast). Focus-visible stays clearly visible.
3. **Header**: `a.logo` = small serif text wordmark (config.title), top-centre at `top: var(--frame-block)`, z-index stays logo layer. Desktop nav (≥ 40rem): mono, top-right at frame insets, aligned to wordmark baseline.
4. **Mobile menu** (< 40rem): `<details class="menu"><summary>Menu</summary><nav>…links…</nav></details>` inside header chrome; no JS. Desktop shows the same nav inline (single nav markup if feasible: details open/always-visible via CSS on desktop, or separate desktop nav + details — worker picks the simpler accessible option, no duplicate landmarks without labels). Panel: `background: var(--paper) var(--paper-texture, none)` (texture hook; paper.png arrives M4), `mask-image` + `-webkit-mask-image: linear-gradient(#000 calc(100% - 3rem), transparent)`. Any transition only under `prefers-reduced-motion: no-preference`. No SVG feTurbulence.
5. **Footer**: left mono `© {year} Simonas Sankauskas · RSS` (keep visible feed link); right `<button type="button" class="theme-toggle" disabled aria-label="Theme (coming soon)">Auto</button>` — visible for layout, not a tab stop until M3 enables it. Padding = frame vars. Soft paper scrim behind footer (gradient from `--paper` ~85% → transparent) for contrast over troughs.
6. **Hero / horizon**:
   - CSS default `:root { --scene-horizon-from-bottom: 59.05vh; }` (+ `59.05dvh` override line).
   - `static/ocean.js`: in existing onResize (and at init), `document.documentElement.style.setProperty('--scene-horizon-from-bottom', canvas.clientHeight * H + 'px')` where `H = 0.5 + 0.75 * Math.tan(0.12)` with a comment cross-referencing `ocean.frag.glsl` camera consts. Must run even before shader-ready; harmless in fallback (CSS default applies if JS never runs). Free bytes by trimming comments — ocean.js must stay < 10,240 B.
   - `templates/index.html`: `<section class="hero">` with `min-height: 100svh; display:flex; flex-direction:column; justify-content:flex-end; padding-bottom: calc(var(--scene-horizon-from-bottom) + gap)` so text sits on the sky just above the horizon, never on the water. Must not collide with header at 844×390 landscape.
   - `content/_index.md`: trim to name (h1) + role line; drop the link list (nav covers it).
7. Validate: `zola check`, `zola build`, `node --check static/ocean.js`, `wc -c static/ocean.js`, curl 200 for fonts, screenshots via `/tmp/pw/shot.mjs` (outside repo) at 1440×900, 1280×800, 390×844, 844×390, and NOGL=1.
