Question: best implementation plan for M0 of PLAN.md given scout context (`.council/M0-scout.md`).
Scope: M0 checklist only. Non-goals: M1–M6 (shader JS, fonts, tokens, theme, htmx, WebP/srcset, 404/OG), PLAN non-goals.

## Plan (ordered steps)

All on branch `rewrite`. No push, no deploy.

1. **Teardown.** `git mv public/images static/images`, `git mv public/favicon.ico public/ballistic-wizard-1.0.0.apk static/`; then
   `git rm -r pages styles scripts public/fonts next.config.js theme.config.js package.json yarn.lock`. `git ls-files public` must be empty.
2. **Photos.** Resize in place, same filenames (old URLs keep working):
   `sips -Z 2400 -s formatOptions 80 static/images/DSCF2021.JPG static/images/R1-09309-017A.JPG`. Originals remain in git history only. WebP/`<picture>`/srcset → M4.
3. **config.toml** (hand-written, not `zola init`): `base_url = "https://simonas-dev.vercel.app"`, `title = "Simonas Sankauskas"`, `description`, `compile_sass = false`, `build_search_index = false`, `generate_feeds = true`, `feed_filenames = ["feed.xml"]`, no taxonomies, `[markdown]` defaults. (`minify_html` left off for now — readability while scaffolding.)
4. **templates/feed.xml** — RSS 2.0, adapted from Zola 0.23.6 built-in `rss.xml` (custom filename needs a template; old feed was RSS). Absolute links.
5. **Templates.** `base.html`: `<html lang="en">`, charset, viewport, `<meta name="color-scheme" content="light dark">`, title, description, `<link rel="alternate" type="application/rss+xml" href="/feed.xml">`, favicon, `styles.css`. Body order:
   skip link → `<canvas id="ocean" aria-hidden="true">` (fixed, z 0, pointer-events none) → `<a class="logo" href="/">` (z 10) → `<div class="page"><main id="main">{% block content %}</main></div>` (z 100) → `<header class="chrome">` nav (About/Posts/Photos) + `<footer class="chrome">` (© year Simonas Sankauskas, RSS link) (z 200). **No `<script>`.**
   `index.html`, `page.html`, `section.html`, `post.html` extend base (post shows title + date).
   `static/styles.css`: layer custom properties `--z-canvas:0; --z-logo:10; --z-page:100; --z-chrome:200`, positioning, body `#faf9f6`/`#353431` baseline, visible `:focus-visible`, skip-link. Bare layout only.
6. **Content.**
   - `content/_index.md`: home — name, role line ("Senior Software Engineer, Android"), links to About/Posts/Photos.
   - `content/about.md` (path `about`): old `pages/index.mdx` body verbatim (7 years line + GitHub/Instagram/LinkedIn links).
   - `content/photos.md`: two images with alt text, width/height attrs, stray `*/}` dropped.
   - `content/posts/_index.md`: `sort_by = "date"`, `page_template = "post.html"`.
   - `content/posts/ballistic-wizard.md`: `date = 2024-06-27`, `aliases = ["/posts/wizard"]`, drop tag/author, fix "Andorid" typo, image with alt.
   - about/photos have no date → stay out of feed.
7. **vercel.json**: `"framework": null`, `installCommand` downloads pinned `zola-v0.23.6-x86_64-unknown-linux-gnu.tar.gz`, `buildCommand: "./zola build"`, `outputDirectory: "public"`, `trailingSlash: true`, 301 `redirects`: `/posts/wizard` → `/posts/ballistic-wizard/`, `/tags/:path*` → `/posts/`. (Zola alias kept too, for `zola serve` and non-Vercel hosts.)
8. **README.md** (what, `zola serve`/`zola build`, deploy notes, Zola version) and **.gitignore**: remove only the legacy Nextra comment lines.
9. Validate: `zola check`, `zola build`, acceptance checks below.
