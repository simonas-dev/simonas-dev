# M7 — Video page

Question: best implementation plan for M7 of PLAN.md given `.council/M7-scout.md`.
Scope: M7 checklist only. Non-goals: other milestones, re-encoding (assets are
pre-encoded in `~/Projects/simonas-dev-video/out/`).

## Plan (ordered steps)

1. **Assets.** Add `*.mov` (and `*.mkv`) to `.gitignore`. Copy only the 8 `*.mp4` and 4
   `poster-*` files from `~/Projects/simonas-dev-video/out/` into `static/video/`, names
   unchanged (not preview.html/README). Verify each mp4 with ffprobe: 0 audio streams,
   moov before mdat, ~12.25 s, codec/dimensions match the `<source type>` strings.
2. **Content.** `content/digital-sun.md`: `title = "Digital Sun"`, `template = "video.html"`,
   short `description`, **no `date`** (keeps it out of feed.xml).
3. **Template** `templates/video.html` extends `base.html`; renders inside `#main`:
   `<section class="video-page">` (never `.content-surface`) containing
   - `<h1 class="video-caption">{{ page.title }}</h1>` (mono caption, the page h1)
   - `<picture class="video-poster">`: `<source media="(orientation: portrait)" type="image/avif" srcset="/video/poster-portrait.avif">`,
     portrait webp, landscape avif, `<img src="/video/poster-1080.webp" alt="" fetchpriority="high">`
   - `<video muted loop playsinline disablepictureinpicture disableremoteplayback aria-hidden="true" preload="none">`
     with the 8 `<source>` elements copied verbatim from preview.html (order, media, codecs), paths `/video/…`.
     **No `autoplay`, no `poster`, no `controls`** (JS starts playback; see decisions).
4. **CSS** (`static/styles.css`, scoped to `.video-page` / `body:has(.video-page)`):
   - `.video-page` fixed `inset:0`, background `#000`; picture/img and video fixed, cover the viewport, `object-fit: cover`.
   - video `opacity:0`, `.playing` → 1 with a ~900ms `var(--ease)` fade (poster stays beneath).
   - `video::-webkit-media-controls, video::-webkit-media-controls-start-playback-button { display:none !important; -webkit-appearance:none }` (iOS LPM overlay).
   - Swap animation on `.video-page` is opacity-only (no transform; transformed ancestor breaks `position:fixed`).
   - `body:has(.video-page)`: black bg, light ink `#e8e6e1` on logo/chrome/caption/open menu panel in **both** themes;
     no header scrim / footer paper gradient. Raise `.logo` above the page layer (z10 < z100) on this page.
   - Chrome + logo + caption dimmed to **opacity 0.55**; 1 on `:hover`, `:focus-within`, `details[open]`.
   - `.video-caption`: mono, `var(--mono-size)`, weight 400, bottom-left inside the frame (`--frame-block`/`--frame-inline`), clear of the footer.
5. **ocean.js** (≤ 11,264 B raw): extract the visibilitychange restart into a named `wake()` that
   `stopLoop()`s when `document.hidden || state.paused`, else restarts as today; expose `state.wake`;
   `if (state.paused) return;` at the top of `frame()` (covers cold load / context restore while paused).
   Policy stays in site.js.
6. **site.js**:
   - `oceanMode()` (or new `videoMode()` called from the same places: initial run, afterPageChange incl. historyRestore,
     `pageshow`, reduce-motion change): `ocean.paused = !!document.querySelector('.video-page'); ocean.wake && ocean.wake()`.
   - Video start: if reduced motion, `navigator.connection?.saveData`, or `effectiveType` matches `/2g/` → do nothing
     (poster only, zero mp4 requests). Else `v.muted = true; v.play().then(..).catch(()=>{})`; add `.playing` on the `playing` event.
     Reduce-motion turning on → pause + remove `.playing`.
   - `visibilitychange`: pause when hidden, re-run start when visible.
   - htmx `beforeSwap` (validated path): `video.pause()`. After the swap, if the tracked video is detached: remove its
     `<source>` children + `removeAttribute('src')` + `load()` to free the decoder (history snapshot already taken, unaffected).
7. **Nav** (`templates/base.html`): add `Video` → `/digital-sun/` in `nav.nav-inline` and the `<details>` menu panel,
   with `aria-current` matching the Photos pattern. Photos page unchanged.
8. **vercel.json**: `headers` for `/video/(.*)` → `Cache-Control: public, max-age=86400` (not immutable; filenames are reused by encode.sh).
9. `zola build` + `zola check`; update README if it lists pages/static layout.
